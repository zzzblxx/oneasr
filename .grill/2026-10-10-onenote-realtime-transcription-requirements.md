# Current Summary

本项目面向 Windows 11 上的 Microsoft 365 桌面版 OneNote，拟开发一款用于线下会议记录的轻量、低延迟实时语音转写插件。用户在 OneNote 中同时进行手写和 OneNote 原生录音时，插件持续采集设备麦克风实际收到的会议语音，通过标准模型接口调用外部 ASR 服务，并将纯文字追加到本次转写所绑定的原始页面，不干扰 OneNote 的输入焦点、手写和原生录音。ASR 服务可以部署在本地或云端，其进程生命周期不由插件管理。

# Goal / Intent

- 在使用 OneNote 手写、键盘记录和浏览页面的同时，自动把环境语音转换为文字并持续写入笔记。
- 保持 OneNote 原生体验，避免转写过程影响手写流畅度或页面操作。
- 插件通过统一的标准模型接口兼容本地或云端 ASR 服务。
- 除插件外，项目还需提供一条经过验证的本地 ASR 使用路径；可以直接选择并适配成熟的现成服务，无需为本项目自研 ASR 服务。
- 允许插件转写文字、用户手写内容和 OneNote 原生录音三者同时工作。

# Confirmed Requirements

## OneNote 集成

- 以 OneNote 插件形式提供功能入口，优先采用 C# / COM 技术路线。
- 在 OneNote 功能区提供“开始转写”“暂停转写”“停止转写”操作；暂停后应可继续。
- 开始转写时自动获取并绑定当前笔记页面。
- 转写期间即使用户切换页面，本次会话仍写入开始时绑定的目标页面。
- 插件与 ASR 引擎解耦，只连接标准模型接口；ASR 可以位于本地或云端，插件不负责启动、停止或守护 ASR 进程。

## 实时语音识别

- 首期核心场景为线下会议记录，只处理设备麦克风实际采集到的声音；麦克风未收到或质量不足的声音无需通过其他渠道补偿。
- 通过 Windows 麦克风持续采集环境声音。
- 首期直接使用 Windows 当前默认输入设备，不在插件内提供麦克风选择器。
- 通过标准模型接口进行实时识别，允许连接本地或云端 ASR 服务。
- 接口优先采用业界通用、便于本地与云端互换的兼容协议，避免与单一 ASR 实现绑定；首选方向为 OpenAI 兼容的语音转写接口族，具体实时协议在技术预检中确认。
- 优先支持中文，同时兼顾中英文混合语音。
- 支持自动断句、标点符号和静音检测。
- 优先评估 FunASR / Paraformer、SenseVoice 等开源模型。
- 插件不自行执行说话人分离；如果 ASR 服务返回说话人标签，则以“说话人 A/B/C”等匿名标签显示，否则仅显示转写正文。

## OneNote 写入

- 自动创建独立的语音转写文本区域。
- 以已完成的句子或短段落为单位持续追加，不逐字刷新。
- 只写入转写正文，不添加时间戳。
- 不抢占输入焦点，不影响触控笔手写、键盘输入或页面操作。
- 不覆盖或修改页面已有内容。
- 转写进行中不考虑用户直接编辑插件生成文字的场景；用户通过旁边手写内容进行批注，插件无需处理转写区域内的并发人工修改。
- 不接管 OneNote 的录音或时间轴能力；录音、时间轴及其关联行为均由 OneNote 原生功能负责。
- 转写内容可以采用独立区域、分区或分块等 OneNote 官方接口实际支持的形式；产品不预先限定固定位置或容器形态。

## 转写控制

- 插件提供 ASR 配置界面，至少包含服务地址、API Key、模型名和“测试连接”；本地服务可不填写 API Key。
- 服务地址和模型名可存入普通配置；API Key 必须使用 Windows Credential Manager 或等效的当前用户安全存储，不得以明文写入配置文件或日志。
- 首期只保存一套当前 ASR 配置，不提供多套配置的命名、管理或快速切换功能；配置结构应避免阻碍后续扩展。
- 首期全局只允许一个活动转写会话；会话进行中不能在其他页面再次开始，必须先停止当前会话。
- 开始：绑定当前页面，启动麦克风采集并连接已配置的 ASR 接口。
- 暂停：暂停语音识别，保留已转写内容。
- 继续：恢复语音识别并继续追加。
- 停止：结束识别并保留全部已写入内容。
- 服务不可连接或接口不可用时，插件只提示 ASR 服务不可用，不尝试启动、停止、安装或修复服务。
- 转写期间 ASR 断开时，插件以非模态状态提示（如按钮状态和悬停说明）标识不可用并自动重连，不弹出会打断手写或 OneNote 操作的阻塞窗口。
- 断线期间不缓存音频；恢复连接后只从当时的实时声音继续转写，断线期间内容允许缺失。
- 绑定的目标页面被删除或变得不可写时，本次转写立即结束；不保留尚未写入的文本或音频，不改绑其他页面，也不继续后台识别。

## 运行与质量

- 运行环境为 Windows 11、Microsoft 365 桌面版 OneNote。
- 首期是面向用户本人目标设备的可安装 MVP，只保证在 ROG Flow Z13 KJP 上完成安装和验收。
- 优先适配 ROG Flow Z13 KJP 的 AMD 平台，允许 CPU 推理，后续再考虑 GPU/NPU 加速。
- 从一句话结束到稳定写入 OneNote，以典型 3 秒内、通常不超过 5 秒作为初始优化目标；具体阈值可根据目标设备实测效果，在识别稳定性与延迟之间调整。
- 插件不额外保存原始录音；连接云端 ASR 时，音频传输遵循用户配置的服务端点。
- 支持至少连续 4 小时的单次会议转写；期间不得崩溃、无故停止转写或出现持续异常的内存增长。异常退出不应造成已写入笔记丢失。
- 通过 OneNote 官方接口操作页面，不修改 OneNote 内部文件，不依赖非公开接口。

# Constraints

- 首期必须能够在目标 AMD 设备上使用 CPU 推理。
- 不额外保存原始录音。
- ASR API Key 不得明文落盘或进入日志。
- 只使用 OneNote 官方公开接口写入页面。
- 不得破坏或干扰 OneNote 原有笔记、输入焦点、手写和键盘操作。
- 插件采集麦克风和 OneNote 原生录音必须能够同时运行，不能互相独占或中断音频输入。

# Key Decisions

- OneNote 前端插件与 ASR 引擎进程解耦。
- 每次转写会话绑定开始时的页面，后续页面切换不改变目标。
- 采用按句或短段落的增量提交方式，而非逐字刷新。
- 首期以 CPU 可用为交付底线，硬件加速延后评估。
- 原始音频默认仅用于实时处理，不落盘保存。
- 说话人区分由 ASR 服务提供，插件只消费和显示服务返回的匿名标签；没有标签时正常写入正文，不影响首期可用性。
- 首期不直接采集系统播放声音，也不专门适配线上会议音频回路。
- 转写输出不附加时间戳；OneNote 原生录音和时间轴不属于插件职责。
- 转写区域的具体位置和容器形式服从 OneNote 官方接口能力，不单独指定版式；但仍须避免覆盖或修改已有内容。
- 首期音频输入设备配置复用 Windows 系统设置。
- 插件不管理 ASR 服务进程生命周期；本地与云端差异由统一接口和端点配置屏蔽。
- 项目提供一个经过验证的参考本地 ASR 方案，允许选用成熟现成服务；只有现成方案无法满足需求时才考虑自建适配层或服务。
- ASR 的部署、启停和运行维护完全在插件职责之外；插件只负责配置、连接检测、调用和错误提示。
- ASR 断线采用“非打断提示＋自动重连＋不缓存音频”的恢复策略。
- 首期仅维护一套当前 ASR 配置。
- 转写期间不支持或保障对已生成转写文字的并发编辑；旁注由 OneNote 手写区域承担。
- 页面绑定随页面生命周期结束；目标页面失效即结束本次转写，不恢复、不迁移、不缓存。
- API Key 使用 Windows 当前用户范围的安全凭据存储。
- 首期交付采用单设备 MVP 范围，不承担面向公众分发所需的广泛硬件兼容、正式代码签名、自动更新和通用安装支持。
- 首期采用单活动会话模型，避免页面绑定、麦克风和 ASR 连接状态冲突。

# Acceptance Criteria

- 用户可在 ROG Flow Z13 KJP 的 Windows 11、Microsoft 365 桌面版 OneNote 环境中安装该 MVP，并从 OneNote 功能区使用核心能力。
- 用户可从 OneNote 功能区开始、暂停、继续和停止一次转写会话。
- 同一时间只能存在一个活动转写会话；已有会话未停止时不能在其他页面开始新会话。
- 开始后自动绑定当前页面，并创建独立转写区域。
- 已完成的句子或短段落能够持续追加到绑定页面，页面切换后仍写入原页面。
- 转写不会覆盖已有笔记，也不主动抢占 OneNote 输入焦点。
- 插件转写、触控笔手写和 OneNote 原生录音能够同时运行，彼此不被插件中断。
- 在目标设备上同时运行插件转写、触控笔手写和 OneNote 原生录音时，不出现可感知的新增笔迹延迟、丢笔或输入焦点跳转。
- 目标设备上的典型转写延迟以 3 秒内为优化目标，通常不超过 5 秒；最终合理阈值可依据实测识别效果确认。
- 连续转写 4 小时期间不崩溃、不无故停止，且内存占用不持续异常增长。
- 插件能够通过同一接口配置连接本地或云端 ASR 服务，且不负责管理 ASR 进程的启停。
- 用户可配置服务地址、API Key 和模型名并测试连接；服务不可用时获得明确提示，插件不会擅自管理服务进程。
- API Key 不会以明文出现在配置文件或日志中，只能存入 Windows 当前用户安全凭据存储或等效安全机制。
- 转写期间服务断开时，插件不会弹出阻塞窗口或中断 OneNote 操作；会显示状态、自动重连、不缓存断线音频，并在恢复后继续实时转写。
- 项目至少验证一个现成本地 ASR 服务可在目标 AMD 设备上通过 CPU 推理，并能由插件经通用接口调用。
- 正常停止或进程异常后，已经成功写入 OneNote 的内容仍然保留。
- 绑定页面被删除或不可写时，转写立即结束，不向其他页面写入，也不保留未写入内容。
- 插件不落盘保存原始录音；是否上传音频取决于用户配置的是本地还是云端 ASR 服务。
